# Charte graphique — Alinea

## Logo

Le logo d'Alinea sera utilisé comme élément principal de l'identité visuelle de l'application.

Il doit conserver ses proportions et ne pas être déformé.

---

## Typographie

### Police principale — Inter

**Inter** est utilisée pour la majorité de l'interface : textes, formulaires, boutons, menus et informations.

Elle est choisie pour sa bonne lisibilité sur écran et son style sobre, adapté à une application contenant beaucoup de texte et de champs.

### Police secondaire — Manrope

**Manrope** est utilisée principalement pour les titres et les éléments nécessitant davantage de mise en valeur.

Elle permet de différencier les titres du reste de l'interface tout en restant proche du style simple et moderne d'Inter.

### Police tertiaire — JetBrains Mono

**JetBrains Mono** est réservée aux contenus techniques ou structurés lorsque cela est utile : valeurs, données générées, extraits JSON ou informations liées aux traitements.

Son utilisation reste ponctuelle afin de ne pas alourdir l'interface.

### Utilisation

- Titres principaux : **Manrope**
- Titres secondaires : **Manrope**
- Textes courants : **Inter**
- Formulaires et boutons : **Inter**
- Données techniques : **JetBrains Mono**  

---

## Composants

L'interface utilisera principalement :

- boutons ;
- champs de formulaire ;
- cartes ;
- listes ;
- badges d'état ;
- menus.

Les composants conserveront la même apparence sur l'ensemble de l'application.
